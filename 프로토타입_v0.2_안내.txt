STAR DRIFTER / FIRST CONTACT — 프로토타입 v0.2
작성: 2026-09-12

1. 이번 버전의 목표
기존 게임기획서의 최신 축소 범위(여성 주인공, 남성 선장 1명, 통제된
행성 1개)를 실제 플레이 가능한 첫 챕터로 구현했다.
기억을 잃었어도 현재의 선택은 할 수 있다는 주제를 주민의 통신 복구와
도시 개방에 관한 선택으로 경험하게 한다.
엘리시움, 카엘, 세라, 노마드, ORACLE은 이번 데모를 위한 가칭이다.

2. 실행
프로젝트 루트의 Play.cmd를 더블클릭한다.
또는 x64\Release\SimpleGame.exe를 실행한다.
Visual Studio에서는 SimpleGame.sln을 열어 Release / x64로 빌드한다.
필요 환경: Windows, OpenGL 3.3 지원 GPU/드라이버, Visual C++ 런타임.
이번 환경에서는 VS의 v143 빌드 도구 및 Windows SDK를 사용했다.

빌드하면 Shaders와 Resources가 실행 파일 옆으로 자동 복사된다.
실행 시 현재 작업 폴더에 의존하지 않고 실행 파일 기준으로 리소스를 찾는다.
다른 PC에 전달할 때는 EXE뿐 아니라 x64\Release 폴더 전체를 전달한다.
freeglut.dll, glew32.dll도 같은 폴더에 있어야 한다.

3. 조작
Enter: 타이틀에서 여정 시작 / 결말에서 새로운 여정
WASD 또는 방향키: 화면 기준 이동
Shift: 달리기
E: 가까운 주민, 중계기, 기억, 중앙 관리자, 우주선과 상호작용
E / Space / Enter: 대화 글자 표시 완료 및 다음 대사
Q: 공명 탐지 (5초 재사용 대기시간)
M: 행성 지도 열기/닫기 (우측 미니맵 클릭으로도 열기 가능)
J: 항해 일지와 수집한 기억 확인
마우스 휠: 확대/축소
Esc: 일시정지 또는 지도/일지 닫기
1 / 2 또는 선택지 클릭: 관리자를 만난 후 이야기 선택

4. 플레이 순서
  1) 타이틀에서 Enter를 누르고 노마드 착륙장에 도착한다.
  2) 금빛 목표 표식을 따라 주거구역 주민 세라에게 가서 E를 누른다.
  3) 주거구역, 정원, 기록보관소의 중계기 세 곳을 원하는 순서로 복구한다.
     M으로 구역과 신호 위치를, J로 현재 목표를 확인할 수 있다.
  4) 선택 활동: 착륙장·정원·기록보관소의 기억 조각 세 개를 수집한다.
  5) 중앙 첨탑의 관리자와 대화한다.
  6) 즉시 개방과 주민 의회 / 주민 투표에 따른 단계적 개방 중 선택한다.
  7) 변화한 도시의 주민과 다시 대화하거나, 노마드로 돌아가 챕터를 마친다.

5. 주요 개선
화면:
  - 1440x900 논리 해상도, 기본 1280x800 창, 창 크기 변경 시 비율 유지.
  - 전용 우주 배경, 카메라에 따른 배경 시차, 부드러운 카메라 추적과 줌.
  - 착륙장 / 주거구역 / 정원 / 기록보관소 / 중앙 첨탑의 다섯 구역.
  - 입체 시설, 우주선, 옥상 장비, 발광 중계기, 창문, 난간, 그림자와 부유 입자.
  - 인물과 건물 깊이 정렬, 주인공을 가리는 건물의 부분 투명 처리.
  - 초상화가 포함된 한글 대화창, 퀘스트 안내, 미니맵, 전체 지도, 항해 일지.

플레이:
  - 키 반복이 아닌 델타타임 이동, 대각선 속도 정규화, 연속 충돌 검사.
  - 플레이어가 지나온 경로를 따라가는 선장, 걷기 동작과 좌우 방향 전환.
  - 대화 상태, 텍스트 순차 표시, 상호작용 우선순위.
  - 중계기 3개, 선택적 기억 3개, 2개의 이야기 선택 결과, 챕터 결말.
  - 복구/결말 상태에 따라 지도 표시, 조명, 주민 대사, 결말 문구 변화.
  - 지도·일지·일시정지 중 탐험 시간 정지, 포커스 이탈 시 이동 입력 해제.

6. 소스 구조
Main.cpp: 창 생성, 콜백, 리소스 경로, 프로그램 종료와 실행 옵션.
GameWorld.h/.cpp: 맵/충돌/이동/동료/대화/퀘스트/선택 상태.
Game.h/.cpp: 화면 구성, 월드 표현, HUD, 지도, 일지, 대화와 타이틀.
Canvas.h/.cpp: 배치 방식 도형·텍스처 렌더링과 GDI 기반 한글 글꼴 텍스처.
Renderer.h/.cpp: 기존 셰이더/텍스처/화면 합성 기능 및 리소스 해제.
PrototypeVerification.cpp: 충돌 경로를 이용한 플레이 검증 및 프레임버퍼 캡처.

기존 SimpleGame.cpp는 이전 프로토타입 참고용으로 보존했다.
현재 빌드의 진입점은 Main.cpp다. 둘을 동시에 빌드하면 main 중복이 되므로
프로젝트 파일에서 기존 SimpleGame.cpp는 컴파일 대상에서 제외했다.

7. 검증 방법
프로젝트 루트의 PowerShell에서:
  .\x64\Release\SimpleGame.exe --verify
또는 아래처럼 결과 위치를 명시할 수 있다:
  .\x64\Release\SimpleGame.exe --verify --output output\verification-release

검증 모드는 숨긴 게임 창을 사용하며, 데스크톱 캡처 없이 게임 프레임버퍼를
직접 BMP로 저장한다. 결과는 output 아래 verification.txt에 기록한다.
검사항목: 초기 스폰 충돌, 실제 렌더링/GL 오류, 시간 간격별 이동 속도,
대각선 이동, 건물/경계 충돌, 지도 일시정지, 목표까지의 충돌 없는 이동,
기억/중계기 상호작용, 두 선택의 상태 전환, 일지, 귀환 결말, 재시작과 리사이즈.
단위 검증에서 한글 글리프 내용 자체를 자동 판독하지는 않는다.
한글 표시와 패널 겹침은 생성된 프레임을 별도로 시각 확인한다.

8. 이번 결과의 범위와 후속 작업
현재는 유한한 다섯 구역을 자유롭게 오가는 첫 행성의 탐험/스토리 데모다.
무한 월드, 행성 간 무중단 이동, 완성된 대규모 오픈월드는 구현하지 않았다.
전투, 적 AI, 장비/성장, 저장/불러오기, 음향, 두 번째 행성은 후속 개발 대상이다.
진행 상태는 실행 중 메모리에만 유지된다. 프로그램을 닫으면 초기화된다.
맵과 대사는 C++ 데이터에 작성되어 있다. 팀 제작을 위해 외부 맵/대화 데이터
포맷과 에디터를 추가하는 것이 다음 기술 과제다.
이번 선택은 대사·개방 정책·조명·결말을 바꾸며, 별도의 두 행성 맵으로
분기하거나 주민 사회를 장기 시뮬레이션하는 시스템은 아니다.
월드 인물은 코드로 그린 스타일화된 도형 캐릭터이며 최종 다방향 스프라이트와
애니메이션, 최종 캐릭터 디자인은 추후 아트 작업에서 교체할 수 있다.

9. 아트 출처
배경과 대화 초상화는 이번 작업에서 내장 이미지 생성 도구로 새로 제작했다.
외부 게임의 캐릭터나 화면을 가져오지 않았다.
저장 위치와 생성 프롬프트 원문은 SimpleGame\Resources\ArtNotes.txt에 있다.
시설, 캐릭터의 월드 표현, 조명, 도형 UI는 게임 코드에서 렌더링한다.
