# STAR DRIFTER 로우폴리 모델 팩

리깅·키프레임 애니메이션과 엘리시움 몹 7종이 추가된 버전은 **[Rigged/README.md](Rigged/README.md)**를 참고한다. 아래는 최초 정적 모델 팩에 대한 안내다.

2026-10-20 제작. 게임기획서와 현재 프로젝트의 캐릭터·지역 설정을 참고한 **모델링 전용 결과물**이다. 게임 소스, 프로젝트 빌드, 실행 파일, 기존 주인공 아트에 적용하지 않았다.

## 파일 열기

- `StarDrifter_LowPoly_Library.blend`: 편집 가능한 전체 원본. Blender 4.2 LTS에서 제작했다.
- `Meshes/NPC/`: 재사용 캐릭터 파트 26개, 파트당 GLB 1개.
- `Meshes/ELY/`: 엘리시움 환경 17개.
- `Meshes/RUI/`: 유적 행성 환경 17개.
- `Meshes/COM/`: 공용 환경 6개. 노마드 우주선과 착륙대 포함.
- `Previews/`: 캐릭터 전체 조합, 캐릭터 확대, 두 행성의 실제 모델 렌더 이미지.
- `Data/asset_catalog.json`: 메시 이름, 파일 경로, 파트 인덱스, 축·원점, 삼각형 수, 재질 목록.
- `Data/npc_presets.json`: NPC 16개 각각의 파트·색상 인덱스.
- `Data/npc_part_indices.csv`: 같은 NPC 인덱스 정보를 표로 확인하는 파일.
- `Data/palettes.json`: 피부·머리·의상·포인트 색상과 재질 역할.
- `Data/mesh_inventory.csv`: 전체 66개 메시 목록.
- `Data/model_validation.json`: 원본 메시의 형상 및 인덱스 점검 결과.
- `Data/glb_validation.json`: 개별 GLB 파일의 재검사 결과.

## 디자인

캐릭터는 맨발 기준 신장 1.80m, 머리 높이 0.60m의 약 3등신이다. 머리카락과 모자는 신장을 조금 넘는다. 6~10각형 단면, 평평한 면 음영, 단색 재질로 작은 화면에서도 실루엣이 읽히도록 했다. 몸형 2개는 얼굴 윤곽과 어깨 폭을 달리하고 장착 위치는 공유한다.

엘리시움은 통제 시스템과 문명 붕괴 이후의 개척지를 표현한다. 청회색 금속 거주동·정비소·기록보관소, 통제 첨탑, 검문소, ORACLE 단말, 중계기와 경비 기계를 만들었다. 청록 신호등과 따뜻한 창문을 함께 배치한다. 정원 나무는 수형이 작고 정돈되어 있으며 풀은 메마른 색이다.

유적 행성은 풍화된 석조 건물과 살아 있는 청록빛의 대비를 사용한다. 성소, 석문, 부서진 기둥, 문양 석비, 제단, 수정, 발광 우산나무, 양치식물, 이끼 바위를 만들었다. 유적 행성의 인물·정확한 건물 설정이 아직 확정되지 않아 이곳의 NPC는 **탐사대 디자인 시안**으로 기록했다. 새 인물 이름이나 스토리 확정 사항을 추가하지 않았다.

풀·나뭇잎·고글·얼굴 요소도 실제 두께를 가진 3D 형상이다. 이미지 평면, 빌보드, 외부 텍스처, 외부 유료 모델을 사용하지 않았다. 건물은 실외용 외형 모델이며 실내 공간이나 작동하는 문은 포함하지 않는다.

## NPC 조합 규칙

모든 인덱스는 **해당 슬롯 내부의 0부터 시작하는 번호**다. 전체 메시 배열의 번호가 아니다. 선택하지 않는 선택 슬롯은 `-1`이다. 기존 번호를 바꾸지 말고 새 파트를 마지막 번호에 추가하면 데이터 연결을 유지할 수 있다.

| 슬롯 | 인덱스와 파트 | 필수 여부 |
|---|---|---|
| `body` | 0 남성 몸형, 1 여성 몸형 | 필수 |
| `hair` | 0 짧은 크롭, 1 단발, 2 긴 생머리, 3 긴 묶음머리, 4 짧은 넘긴머리 | 선택, -1은 머리카락 없음 |
| `top` | 0 주민 상의, 1 작업복, 2 갑옷, 3 군복, 4 선장 코트, 5 탐사복 | 필수 |
| `bottom` | 0 기본 바지, 1 카고 바지, 2 장갑 바지 | 필수 |
| `footwear` | 0 발목 부츠, 1 작업 부츠, 2 전투 부츠 | 필수 |
| `accessory` | 0 스카프, 1 호흡 마스크, 2 고글, 3 어깨 가방, 4 배낭 | 선택 |
| `headgear` | 0 순찰 모자, 1 군용 헬멧 | 선택 |

몸형에는 머리·얼굴·목·의복 안쪽의 상체·팔·손이 포함된다. 하의와 신발은 별도 파트다. 상의는 남녀 공용 장착 범위를 공유한다. NPC마다 완성된 캐릭터 메시를 복사하지 않고 슬롯별 원본을 재사용한다. Blender 미리보기 NPC도 같은 원본 메시 데이터를 공유한다.

모자나 헬멧을 쓰는 조합은 머리카락을 `-1`로 지정한다. 서로 다른 머리카락이 모자 밖으로 뚫리는 것을 막기 위한 조합 규칙이다. 액세서리는 슬롯당 하나만 선택한다. 머리카락을 유지하는 모자용 전용 헤어와 다중 액세서리 조합은 이 팩에 포함되지 않는다.

피부 5색, 머리 6색, 의상 8색, 포인트 6색은 메시를 추가하지 않고 재질 교체로 적용한다. 슬롯은 `skin`, `hair`, `cloth`, `trim`이며 GLB의 `M_NPC_skin`, `M_NPC_hair`, `M_NPC_cloth`, `M_NPC_trim`에 대응한다. 색상 값은 선형 RGB다. NPC의 상·하의는 `cloth` 팔레트를 공유한다. 금속·신발 등 고정 재질은 그대로 사용한다.

세라의 실제 예시:

```json
{
  "npc_id": "NPC_001_Sera",
  "part_indices": {
    "body": 1,
    "hair": 1,
    "top": 1,
    "bottom": 0,
    "footwear": 0,
    "accessory": 3,
    "headgear": -1
  },
  "palette_indices": { "skin": 1, "hair": 0, "cloth": 0, "trim": 1 }
}
```

카엘·세라는 스토리의 기존 인물이다. 정비공·기록관리인은 소스에서 확인한 대사 역할을 바탕으로 한 디자인 시안이다. 현재 대사에서는 같은 0 이외 주민 variant가 퀘스트 단계에 따라 두 역할의 대사를 표시하므로, 두 개의 확정된 런타임 NPC ID로 간주하지 않았다. 나머지는 주민·경비·탐사대 조합 시안이다. `npc_id`는 이 아트 팩의 안정적인 식별자이며 런타임 ActorId와 무관하다.

## 다른 작업에서 적용할 때

캐릭터 파트는 **모두 원점 `(0, 0, 0)`, 회전 0, 배율 1**로 조립한다. 원점은 발바닥 중앙이다. 같은 NPC 루트 아래에 선택한 파트를 겹쳐 배치하고 루트만 월드 위치로 옮긴다. 파트를 바운딩 박스 중심으로 개별 정렬하거나 재중앙화하면 조립 위치가 어긋난다.

Blender 원본은 Z 위쪽, -Y 정면이다. GLB는 Y 위쪽, +Z 정면으로 변환되어 있다. Blender의 `(x, y, z)`는 GLB의 `(x, z, -y)`에 대응한다. 두 형식을 섞어 조립하지 않는다. 단위는 미터다.

환경 원점은 지면 중심을 기준으로 한다. 공중에 떠 있는 경비 드론은 투영된 지면 중심을 원점으로 삼아 기본 부양 높이를 형상에 포함한다. 벽과 바닥은 2m 모듈이다. 바닥은 원점 위로 두께가 있으므로 캐릭터를 올릴 때 바닥 상면 높이를 사용한다. 모델별 정확한 바운딩 박스는 카탈로그에 있다.

`SM_NPC_TOP_002_Armor`처럼 슬롯·번호·형태를 이름에 넣었다. 환경은 `SM_ELY_BLD_003_ControlSpire`처럼 행성·종류·번호·이름으로 구분한다. `ELY`는 엘리시움, `RUI`는 유적, `COM`은 공용이다. `BLD` 건물, `MOD` 배치 모듈, `PROP` 소품, `NAT` 자연물, `UNIT` 기계 유닛, `SHIP` 우주선이다. 오브젝트 이름과 메시 데이터 이름은 일치한다.

모델은 정적인 A 포즈다. 리깅·스키닝·걷기 애니메이션·LOD·충돌 메시·엔진 로더는 포함하지 않는다. 애니메이션 작업에서는 이 공용 체형과 장착 위치에 맞춰 리그를 만들고 파트별 웨이트를 추가해야 한다. 개별 GLB는 한 개의 이름 있는 메시를 유지하며 재질별 primitive는 여러 개일 수 있다. 게임 엔진에서 재질별 드로우콜이 발생할 수 있으며 메시 재사용만으로 드로우콜 감소가 보장되는 것은 아니다.

## Blender 원본 장면

- `00_NPC_Lineup`: NPC 16개 전체. 처음 열리는 장면.
- `03_NPC_Detail`: 카엘·세라·장갑 경비·탐사대 확대.
- `01_Elysium_Kit`: 엘리시움 적용 예시.
- `02_Ruins_Kit`: 유적 행성 적용 예시.
- `90_SourceLibrary`: 66개 원본 메시. 원점이 겹치므로 컬렉션을 나누어 보거나 원하는 메시만 단독 표시한다.

`PREVIEW_` 이름의 받침대·이름표·카메라·조명은 보여주기 위한 요소이며 개별 GLB에는 없다. 환경 적용 예시는 완성된 플레이 맵이나 내비게이션 데이터가 아니다.

## 확인 범위

원본 66개 메시의 중복 이름, 비정상 좌표, 면적 0 삼각형, 열린 경계와 비정상 엣지, 원점과 배율을 확인했다. NPC 16개의 파트 인덱스와 모자·헤어 조합 규칙도 확인했다. 얼굴과 의복, 환경 장면은 실제 렌더로 확인했다. 각 메시에는 로우폴리 제작을 위한 여러 닫힌 형상이 서로 겹칠 수 있다.

추가로 GLB 내부의 메시 이름, 삼각형 인덱스, 재질 연결, 위치 데이터와 파일 목록을 확인했다. 이는 아트 파일 점검이며 게임 실행이나 게임 엔진에서의 로딩·성능 검증은 수행하지 않았다.
