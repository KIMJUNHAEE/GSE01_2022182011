# 여성 개척자 — Tripo 20k 텍스처 수정본

사용자가 제공한 `starrail_player.glb`를 다듬은 모델링 전용 자산입니다. 다운로드 원본은 보존했습니다.

## 눈 정렬과 다리 피부색 수정

양쪽 눈의 들어간 면을 머리카락과 텍스처를 가린 상태에서 확인했습니다. 눈 그림은 아래로 0.027m, 눈썹은 따로 0.035m 이동해 눈동자는 눈 안쪽 면에 남고 검은 윗눈꺼풀 선이 돌출된 능선에 걸치도록 맞췄습니다. 첫 미리보기에서 너무 낮다는 사용자 의견을 반영해 눈 그림을 0.012m, 눈썹을 0.008m 다시 올렸습니다. 입과 얼굴 기본색, 모델 형태와 UV는 유지했습니다. 다리와 노출된 발목은 얼굴과 같은 선형 RGBA (0.72, 0.52, 0.40, 1)를 적용했습니다. 이전의 반팔·머리색 수정은 보존했습니다.

이번 작업의 texture_preservation_validation.json은 직전 수정본과 비교하여 메시 위치·면·가중치·뼈·애니메이션이 동일함을 확인합니다. eye_alignment_report.json에는 이동량과 피부색을 기록했습니다.

## 이전 추가 수정

안쪽 반팔을 흰색으로 바꾸고 사진 왼쪽의 세로 주름을 정리했습니다. 머리카락은 더 진한 중성 회색으로 조정하고 양쪽 눈썹과 속눈썹을 검정색으로 맞췄습니다. 이마에서 머리 재질로 잘못 분류된 면을 얼굴 재질로 돌렸습니다. 다리의 검정 띠·얼룩을 없애고 밝은 흰색 계열로 정리했습니다. 기존 눈 이미지를 Blender에서 재사용했으며 이번 추가 수정에는 새 이미지 생성이나 Tripo 크레딧을 쓰지 않았습니다.

## 이전 텍스처 수정

눈 그림을 새로 만들고 기존 얼굴 위치에 맞춰 전용 2K UV로 배치했습니다. 턱의 회색 띠와 은발에 섞인 살색을 피부·머리카락 영역별로 정리했습니다. 얼굴과 머리카락에서 거친 원본 노멀을 제외하고, 의상의 색 구분과 재질별 거칠기를 조정했습니다. 몸 색상은 4K PNG, 얼굴은 2K PNG, 표면 특성은 4K ORM으로 전달하며 GLB에도 내장했습니다.

삼각형 수·UV·스킨 가중치·뼈대·애니메이션 키프레임은 유지했습니다. 요청한 반팔 왼쪽 세로 주름의 좁은 영역에서만 표면 깊이를 다듬었습니다. 원본 생성 텍스처에서 뭉개진 의상 글자와 작은 장식까지 복원한 것은 아닙니다. 머리카락과 무릎의 기존 형태상 한계는 남아 있습니다.

## 파일

- `Stelle_Tripo_20k_Rigged.blend`: 편집용 모델, 재질, 뼈대, 키프레임과 미리보기 장면. 새 수정본을 확인하려면 이 파일을 다시 여세요.
- `Meshes/PLAYER_Stelle_Tripo_20k.glb`: 텍스처·리깅·애니메이션을 포함한 전달용 모델.
- `Data/player_asset.json`: 파트 이름·인덱스, GLB 노드/메시/뼈 인덱스와 텍스처 정보.
- `Data/animation_clips.json`: 동작 프레임, 반복 여부, 이동·회전 정보.
- `Data/texturing_prompt.md`: 내장 이미지 생성 도구로 만든 눈의 프롬프트와 출처 기록.
- `Textures/`: 새 4K/2K 맵, 투명 눈 원본, 보존한 원본 텍스처. 활성 맵은 player_asset.json에 표시했습니다.
- `Previews/`: 이번 수정본의 정면·후면·얼굴·동작, 수정 전후 비교와 내보낸 GLB 재가져오기 결과.

## 모델과 동작

19,994 삼각형, 이름을 부여한 파트 메시 21개, 뼈 33개입니다. 각 파트와 뼈의 인덱스는 Data에 기록했습니다. 기본 뼈 20개는 기존 NPC와 이름을 맞췄으며 자세를 공유할 때는 비율에 맞는 리타기팅이 필요합니다.

30fps 키프레임 10종: Idle, Walk, Run, Jump, Turn_L_45, Turn_R_45, Turn_L_90, Turn_R_90, Turn_L_180, Turn_R_180.
걷기·달리기는 제자리 반복, 점프는 수직 이동, 방향 전환은 루트 회전을 포함합니다. 머리카락·옷자락·리본도 키프레임으로 움직입니다. Blender에서 뼈대를 선택하고 Action Editor의 PLAYER__ 액션을 선택해 재생하세요. NLA 트랙은 중복 재생을 막기 위해 음소거되어 있습니다.

원본의 장갑 주먹 형태를 유지했으므로 개별 손가락 조작과 표정 모프는 없습니다. 손과 옷이 연결된 원본 영역은 같은 가중치로 유지하고 팔 움직임을 작게 만들었습니다. 큰 새 팔 동작에는 연결부 분리와 표면 보강이 필요합니다.

## 확인 기록

Data/texture_preservation_validation.json은 허용한 반팔 주름 영역 외의 메시와 전체 UV·가중치·뼈·키프레임 동일성을 확인합니다. glb_validation.json은 내장 텍스처 픽셀, 얼굴 UV, 이름·인덱스·스킨·10개 클립을 확인하며 roundtrip_validation.json은 빈 Blender에 다시 가져온 모델의 실제 걷기 변형을 확인합니다. 기존 animation_validation.json과 skin_seam_validation.json은 보존된 모델과 동작의 이전 확인 기록입니다. 게임 적용과 빌드는 별도 작업입니다.
