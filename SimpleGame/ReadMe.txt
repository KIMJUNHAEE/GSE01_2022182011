STAR DRIFTER — FIRST CONTACT

Build SimpleGame.sln using Visual Studio v143, Release / x64.
Run Play.cmd from the repository root or x64\Release\SimpleGame.exe.
The build copies Shaders and Resources beside the executable.

Current entry point: Main.cpp.
SimpleGame.cpp is preserved as the old prototype and is not compiled.

Controls: WASD/arrows move, Shift run, E interact, Q scan,
M map, J journal, mouse wheel zoom, Esc pause, Enter start.
Run with --verify for deterministic traversal/quest tests and framebuffer captures.
See the Korean v0.2 guide in the repository root for the scope and full walkthrough.
