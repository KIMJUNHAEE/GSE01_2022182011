STAR DRIFTER — 레벨 1: 엘리시움 / 파밍과 전투
작성일: 2026-09-14

1. 이번 구현의 범위

기존 2.5D 탐험 프로토타입 위에 첫 행성의 전투·파밍 루프를 추가했다.
행성 안에서 자유롭게 이동하며 세 구역을 원하는 순서로 탐사한다.
착륙장 → 경비 기계 처치 → 전리품 자동 습득 → 성장 → 중계기 복구
→ ORACLE 보스 격파 → 주민의 미래 선택 → 노마드 귀환 순서다.

세라와의 대화, 카엘의 동행, 기억 수집, 마지막 두 선택지는 유지한다.
전투 시작 전에 대화를 반드시 완료할 필요는 없다.
최대 80레벨은 전체 성장 시스템의 상한이며 첫 행성의 권장 레벨이 아니다.
현재 수치는 첫 플레이 테스트용 초안이며 실제 난이도·플레이 시간은 조정이 필요하다.

2. 조작

WASD / 방향키: 화면 기준 이동
Shift: 달리기 (기본 이동 속도의 1.5배)
마우스 이동: 조준
마우스 좌클릭: 사격 / 누르고 있으면 쿨타임마다 연속 사격
E: 가까운 주민·중계기·기억·관리자 단말·우주선과 상호작용
Q: 공명 탐지
M: 지도 (붉은 점은 적, 붉은 큰 표식은 관리자 단말)
J: 항해 일지, 맵 시드, 일부 성장 수치 확인
휠: 확대 / 축소
Esc: 일시정지 / 메뉴 닫기
사망 화면 R: 같은 시드로 처음부터 재도전
사망 화면 N: 새로운 시드로 처음부터 재도전
사망 화면 Esc: 게임 종료

대화·지도·일지·일시정지·사망 중에는 전투가 진행되지 않는다.
다른 창으로 전환하면 탐험은 일시정지된다.
메뉴를 닫은 뒤에는 좌클릭을 새로 눌러야 사격한다.
화면 바깥 여백의 클릭은 전투 입력으로 처리하지 않는다.

3. 사격과 적

발사체는 마우스 방향으로 날아가며 실제 이동한 거리가 사거리에 도달하면 사라진다.
지형 경계와 장애물에 막히며 한 발은 처음 맞은 적 한 명에게만 피해를 준다.
화면 확대와 무관하게 월드 기준 속도·사거리·공격 판정은 동일하다.
점선은 조준 방향이고 끝의 가로 표식은 최대 사거리다. 장애물이 있으면 더 일찍 막힌다.
탄약 제한과 재장전은 이번 파밍 입문 단계에는 넣지 않았다.

근접 경비 드론: HP 32, 접촉 공격 8, 공격 간격 1.1초
원거리 감시기: HP 48, 피해 10, 0.75초 조준 예고 후 발사
각 파밍 구역에 4 / 5 / 5기 배치된다.
착륙장은 일반 적의 추격 대상에서 제외되며 적은 플레이어와 떨어진 위치에 생성된다.
피격 뒤 0.7초 동안 무적이 적용되어 중첩 피격을 완화한다.

중계기는 해당 구역에 배정된 적을 모두 처치한 뒤 복구할 수 있다.
미복구 구역은 전멸 후 25초가 지나고 플레이어가 멀리 떠났을 때 다시 적을 생성한다.
복구한 구역에는 증원이 없으며 보스전 시작 이후에는 모든 증원이 중단된다.
중계기를 복구하기 전 반복 파밍할 수 있고, 복구한 구역은 안전하게 통과할 수 있다.

4. 성장 수치

L = 캐릭터 레벨 (1~80), W = 무기 강화 단계 (0~20)

다음 레벨에 필요한 XP = 60 + 25*(L-1) + 5*(L-1)^2
최대 HP = 100 + 7*(L-1)
발사체 피해 = 12 + 1.8*(L-1) + 4*W
발사 간격(초) = max(0.11, 0.42 / (1 + 0.022*(L-1)) * 0.94^W)
사거리 = 350 + 1.5*min(60, L-1)
이동 속도 = 155 + 0.65*min(40, L-1)
기본 습득 범위 = 55 + 0.8*min(40, L-1)
치명타 확률 = min(20%, 5% + 0.15%*(L-1))
치명타 피해 = 기본 피해의 1.6배

거리와 속도 수치는 확대 전 등각 투영 좌표의 단위 / 초 기준이다.
레벨업 때 현재 HP가 22 증가하되 새 최대 HP를 넘지 않는다.
남은 XP는 다음 레벨로 이월되며 한 번에 여러 레벨 상승할 수 있다.
80레벨에 도달하면 XP 누적을 중지하고 경험치바에 MAX를 표시한다.
중계기 복구 보상은 XP 60과 회복 아이템 1개다.

5. 아이템

영혼석 (보라): 드론은 XP 20, 감시기는 XP 30을 드롭한다.
일반 적 처치 시 아이템과 별개로 XP 8도 즉시 얻는다.
무기 강화 (금색): 강화 +1, 피해와 연사 속도 증가. 최대 +20.
  최대 강화를 초과한 아이템 1개당 XP 40으로 전환한다.
체력 회복 (초록): 최대 HP의 35% 회복.
  HP가 가득 차 있으면 소모하지 않고 바닥에 남겨 둔다.
자석 (청록): 8초간 580 범위의 전리품을 끌어온다. 중첩 시 최대 24초.

가까이 다가가면 별도 키 없이 습득한다.
첫 번째 / 두 번째 / 세 번째 일반 적 처치에서 각각 강화 / 회복 / 자석을 확정 지급한다.
이후 추가 드롭 확률은 강화 22%, 회복 25%, 자석 12%, 추가 없음 41%다.
영혼석은 위 확률과 별개로 모든 일반 적이 드롭한다.
전리품은 이동 가능한 바닥에 배치하고, 자석 이동도 경로와 장애물 검사를 거친다.
아이템 오브젝트는 최대 128개로 제한하고 같은 종류를 합쳐 수량을 보존한다.

6. 랜덤 맵 안전 설계

착륙장과 네 주요 구역을 생성하고 구역 중심·크기·연결 방향·장애물을 변형한다.
연결 통로는 기본 폭 3칸이며 정원에서 보스 구역으로 이어지는 우회 경로도 만든다.
반 칸 간격의 이동 격자를 사용하고 캐릭터보다 약간 넓은 반경으로 검사한다.
각 이동 격자 사이의 중간 경로도 검사해 모서리를 통과하는 잘못된 연결을 막는다.
출발점에서 모든 이동 격자가 연결되고 필수 장치에 접근 가능한지 검사한다.
이동 영역을 분리하는 장애물 후보는 채택하지 않는다.
적·전리품의 위치는 이 이동 격자를 기준으로 잡는다.
적 추격과 자석 습득은 플레이어까지의 공통 경로 정보를 사용한다.

맵 시드는 일지와 사망 화면에 표시된다.
같은 실행 파일과 같은 시드에서는 같은 맵과 초기 적 배치를 재현한다.
정해진 다섯 구역을 변형하는 방식이며 무한 월드 스트리밍은 이번 범위가 아니다.

7. 첫 행성 보스 — ORACLE / 경계 관리자

해금: 중계기 세 곳을 모두 복구하고 중앙 첨탑의 ORACLE 단말에서 E.
HP 640. 보스는 단 한 번 생성되며 격파 뒤 다시 나타나지 않는다.
공격 순서: 조준 확산탄 → 방사 탄막 → 플레이어 위치의 지면 폭격.
조준 공격은 준비 시점의 위치를 겨누므로 이동해 피할 수 있다.
지면 폭격은 붉은 원으로 예고되며 반경 78이다.

1단계: 체력 50% 초과, 1.15초 예고, 확산탄 3발 / 방사탄 8발.
2단계: 체력 50% 이하, 0.85초 예고, 확산탄 5발 / 방사탄 12발.
확산탄 피해 16, 방사탄 피해 14, 폭격 피해 20 / 24.
공격 사이 대기 시간도 2단계에서 짧아진다.
입구를 봉쇄하지 않으므로 후퇴하거나 남겨 둔 회복 아이템을 찾을 수 있다.

격파 보상: 즉시 XP 450, 영혼석 XP 200, 강화 2개, 회복 2개, 자석 1개.
이후 단말에 다시 접속하면 기존의 두 이야기 선택지가 열린다.
선택 완료 후 노마드로 돌아가면 첫 행성이 끝난다.

8. 코드 위치

CombatTypes.h: 플레이어 능력치와 적·발사체·아이템 데이터
LevelOne.cpp: 맵 생성, 연결 검사, 길 찾기, 구역별 적 생성
Combat.cpp: 성장, 사격, 적 AI, 보스 패턴, 피해, 드롭, 습득
GameWorld.cpp: 탐험·대화·중계기·보스·귀환 진행 연결
GameCombat.cpp: 적·총·발사체·전리품·공격 예고·전투 UI·사망 화면
Game.cpp / Main.cpp: 마우스 입력, 화면 좌표 변환, 기존 화면과 연결
PrototypeVerification.cpp: 사용자가 --verify 옵션으로 실행할 수 있는 검증 코드

9. 확인 상태와 플레이 체크리스트

이번 작업에서는 사용자 요청에 따라 빌드·게임 실행·검증 프로그램 실행을 하지 않았다.
코드 읽기, 프로젝트 파일 연결 확인, 코드 스타일 정리, 변경 내용의 정적 점검만 수행한다.
검증 코드가 추가되었다는 사실은 검증 통과를 뜻하지 않는다.

빌드 후 확인할 항목:
  - WASD 이동 중 마우스를 돌려 사격해도 조준 방향이 맞는지.
  - 짧게 클릭하거나 누르고 있을 때 사격과 쿨타임이 자연스러운지.
  - 확대 / 창 크기 변경 후에도 조준점과 발사체 방향이 맞는지.
  - 첫 세 처치의 강화·회복·자석과 영혼석을 확인할 수 있는지.
  - HP가 가득 차면 회복 아이템이 남고, 피격 후 다시 접근해 회복되는지.
  - XP 이월과 레벨업 후 공격력·연사·최대 HP 변화가 표시되는지.
  - 여러 랜덤 맵에서 모든 중계기·기억·단말·우주선에 접근 가능한지.
  - 각 구역의 적을 모두 처치해야 중계기가 작동하는지.
  - 보스 해금, 세 패턴, 2단계, 보상, 이야기 선택, 귀환이 이어지는지.
  - 사망 재도전 시 성장·아이템·보스·입력이 초기화되는지.
  - 대화 / 지도 / 다른 창 전환 중 공격·쿨타임이 멈추는지.

자동 검증 코드는 64개 시드 연결성, 성장 상한, 사격, 습득, 메뉴 입력,
실제 발사체의 보스 격파, 이야기 분기, 재시작 등을 검사하도록 작성했다.
실행 시 만들어지는 캡처는 수동으로 확인해야 하며 화면 구성의 품질을 자동 판정하지 않는다.

현재 미포함: 영구 세이브, 인벤토리 장착 UI, 무기 교체, 음향, 다음 행성.
성장·강화·아이템은 현재 탐사에만 적용되고 게임 종료나 재도전 때 초기화된다.
